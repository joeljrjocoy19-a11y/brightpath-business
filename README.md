# BrightPath Business

A modern, responsive business website template built with HTML, CSS, and vanilla JavaScript.

## Website files

- `index.html` — page content and structure
- `style.css` — colors, layout, and responsive styles
- `script.js` — mobile navigation and automatic footer year

## Preview locally

Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings**.
3. In the left menu, open **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then save.
6. Wait a few minutes and revisit the Pages settings for the published URL.

## Customize before using for a real business

- Replace the BrightPath name and copy with your actual business details.
- Change the contact email `hello@example.com` in `index.html` to your real business email.
- Update the services to match what you actually offer.
- Review all text and links before sharing the website publicly.

This is a static website template. It does not include a backend or a working message form.
